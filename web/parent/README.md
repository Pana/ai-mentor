# 小熊伴学 · 家长管理（网页版）

家长在浏览器里管理家庭，和 iPhone、安卓家长端“设置”里的功能相同：

- 用手机号和密码登录或注册（注册时可填家人发来的 8 位邀请码，加入同一个家庭）；也保留“用家长密钥连接”
- 孩子：添加、修改昵称和年级、删除（会删除这个孩子的全部数据）
- 家长：查看家里的家长（手机号中间打码），生成邀请码并复制邀请信息，把其他家长移出家庭
- 连接孩子的设备：生成 6 位配对码
- 已连接的设备：查看每台设备属于哪位家长，断开设备
- 我的账号：查看手机号、改称呼、改密码；用家长密钥连接的网页可以补设手机号登录

作业录入、批改、每天坚持和奖励规则仍在 App 里，网页版暂时没有。

## 打开

页面由服务端提供，和作业 API 同一个地址：

```sh
cd server && npm start             # 本机：http://127.0.0.1:8787/parent/
```

线上用 `https://<服务器地址>/parent/`。**要用 HTTPS 打开**：用 `http://` 的局域网地址时密码不加密，页面会提示（本机 `127.0.0.1` 除外）。

## 实现

- 纯静态页面（`index.html`、`app.mjs`、`style.css`），不依赖第三方库，直接调用 `/v1/` 接口，见 [服务端说明](../../server/README.md#家庭账号与设备)。
- 这个浏览器登录后算一台家长设备，设备名是“网页（Chrome）”这样的浏览器名。凭证存在这个网站的 `localStorage`，点“退出登录”时服务端同时作废这个凭证。凭证失效（在别处被断开、被移出家庭、改了密码）时页面回到登录。
- 服务端给页面加了严格的 Content-Security-Policy（只允许本站脚本和样式，不允许内联）、`frame-ancestors 'none'` 和 `X-Frame-Options: DENY`（不能被别的网站嵌入），以及 `Referrer-Policy: no-referrer`。
