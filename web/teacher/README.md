# 小熊老师（语音老师，网页版）

孩子直接和小熊说话，小熊边说边在白板上画。说话不用按按钮，小熊讲的时候开口或点一下小熊就能打断。方案、协议和白板元素见 [语音老师技术方案](../../docs/voice-teacher.md)。

状态：页面、白板和对话流程用替身上游在 Chromium 里跑通（`scripts/teacher-web.sh`）。**火山语音识别、语音合成和 DeepSeek 还没有接真实服务测过，iPad Safari 也还没有真机验过。**

## 打开

页面由服务端提供，和作业 API 同一个地址：

```sh
cd server && npm start             # 本机：http://127.0.0.1:8787/teacher/
```

iPad 上用 Safari 打开 `https://<服务器地址>/teacher/`。**麦克风需要 HTTPS**（本机 `127.0.0.1` 除外）：用局域网的 `http://` 地址打开时浏览器不给麦克风，页面会提示并退到只打字。分享菜单里“添加到主屏幕”后可以像 App 一样全屏打开。

第一次打开要连接这台设备，二选一：

- **配对码**：家长在小熊伴学家长端生成 6 位配对码，和孩子的 iPad 配对是同一个流程。
- **家长密钥**：没有家长端时，点“没有家长端？用家长密钥连接”，填服务端 `.env` 里的 `PARENT_BOOTSTRAP_TOKEN`。家里还没有孩子时页面会让你添加一个。

连接后每次打开只需要点一下“开始”（浏览器要求先点一下才能出声）。Safari 默认每次都会问是否允许麦克风；在地址栏的“网站设置”里把麦克风改成“允许”就不再问。右上角 ⚙︎ 可以换孩子或断开这台设备。

## 服务端要配置什么

| 想要的效果 | `server/.env` |
| --- | --- |
| 小熊能回答 | `MODEL_API_URL`、`MODEL_API_KEY`、`MODEL_NAME`（DeepSeek）；想单独指定模型用 `TEACHER_MODEL_NAME` |
| 孩子能说话 | `VOLC_ASR_API_KEY`（火山豆包语音） |
| 小熊能出声 | `VOLC_TTS_SPEAKER`（音色 ID，要和 `VOLC_TTS_RESOURCE_ID` 的版本匹配）；密钥默认沿用 `VOLC_ASR_API_KEY` |

缺哪一项，页面就退到对应的降级：没有识别只能打字，没有合成只显示字幕（每段按字数停留），没有模型时提示服务器未配置。三项都不配、只设 `VOICE_MOCK=true` 时，小熊回复一段固定的竖式演示，可以先看页面和白板。

## 文件

| 文件 | 内容 |
| --- | --- |
| `app.mjs` | 页面：连接设备、选孩子、状态显示、打字、家长设置 |
| `session.mjs` | 一次对话：`/v1/teacher` 协议、轮次、打断、“讲到哪段画到哪段”的播放同步 |
| `audio.mjs`、`capture-worklet.mjs` | 麦克风采集（浏览器回声消除，降到 16 kHz）、开口检测、播放合成的语音 |
| `vad.mjs` | 开口检测：跟随环境噪声；小熊说话时提高门槛，减少回声误打断 |
| `board.mjs`、`calc.mjs` | 白板：文字、竖式、数轴、点子图、线段图、钟面。竖式的结果、进位和退位由页面自己算，不用模型给的数 |

设备凭证存在这台浏览器的 `localStorage`；页面的内容安全策略只允许加载本站脚本。

## 检查

```sh
cd server && npm test        # 协议、白板校验、竖式计算、开口检测、页面和凭证
scripts/teacher-web.sh       # Chromium 端到端：假麦克风说一句话，跑完连接、对话、打断、断线和各尺寸布局，导出截图
```

端到端检查里的模型、识别和合成都是本机替身，只验证页面和协议。

## 真机上要验的

这些在自动检查里验不了，接上真实服务后在 iPad Safari 上过一遍：

1. **回声**：小熊说话时不戴耳机，会不会把自己的声音当成孩子插话（误打断）。多的话调 `vad.mjs` 里的 `strictExtra`。
2. **开口检测**：孩子正常音量说话能不能触发；句中停顿会不会被切成两句（`endAfterMs`，现在是 0.8 秒）。
3. **童声识别**：用孩子的声音测火山识别的准确率，数学说法（“三十八加二十七”）是否转成了数字。
4. **延迟**：说完到小熊开口的时间；合成的音色和语速是否合适（`VOLC_TTS_SPEECH_RATE`）。
5. **DeepSeek 的输出**：是否守住“一行一段”的格式、白板指令的合法率、是否直接说出答案。
6. **Safari 行为**：麦克风打开后小熊的音量是否变小；切到后台、锁屏、来电后回来能否继续；屏幕键盘弹出时输入框是否可见。

已知的取舍：检测到孩子开口就停掉当前讲解。咳嗽或大的环境噪声会误触发，这段讲解就丢了；真机上误打断多的话，改成“先暂停，识别出文字才取消”。
