现在的重点。发现的问题随手记在这里，修好就勾掉。

- [x] 家长批注点“撤销”没反应（Android：撤销按钮读不到最新状态，一直是灰的）
- [x] 批注页的图片不能放大（Android：两指张开放大、拖动，右上角“还原大小”）
- [x] iPhone 批注页也加上两指放大（照片放进 PencilKit 画布里一起缩放，红笔用两指移动，打勾/圈出用单指移动）
- [ ] **AI 自动批改（不着急）**：家长打开批注页时，AI 先判断每道题对不对，在照片上预先标好 ✓ / ○，家长确认或修改后再发给孩子。要先解决的问题：
  - 识别准确率：小学口算、填空比较好判断，应用题、作文先不做

  - 家长始终是最后确认的人，AI 只预标，不直接发给孩子

### 外接摄像头（2026-11-24 开始）

孩子不用拿起平板：USB 摄像头架在桌上对着作业，点一下屏幕就拍。以后小熊老师要能实时看到孩子看到的内容，再一起讨论。

- [x] 第一步：拍照交作业页插着外接摄像头时直接显示实时画面，点画面或“拍第 N 页”就加一页（不用全屏相机，也不用框选）；右上角 ↻ 按摄像头的摆放转正画面，记住设置；插拔即时切换。iPad 的“拍题目”全屏相机用外接摄像头时也是点画面就拍。
- [ ] iPad 实机验证（USB-C iPad，iPadOS 17+）：画面方向、↻ 旋转、拍出的照片方向、插拔、清晰度与对焦
- [ ] 小米 Pad 实机验证：先看系统是否把 USB 摄像头交给应用（`adb shell dumpsys media.camera` 里有没有 external provider，或者应用里出现“系统不让应用直接用它”的提示）。不支持的话，需要在应用里自带 UVC 驱动（libuvc/libusb 一类原生库），工作量另算
- [ ] 小熊老师实时看画面：在同一个摄像头会话上加视频帧输出，按需抽帧发给视觉模型
