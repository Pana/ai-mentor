# 路线图与待办

2026-11-23 定的方向，按优先级排列。

## 定位（2026-11-25 定）

小熊伴学要做的是一个**学习类的个人 Agent**。

- **最大的特点**：持续了解孩子的学习状况，并主动引导孩子去学。主动引导包括提醒写作业、提醒知识盲点。
- **核心卖点**：交互更自然。以语音对话为主；高级一些的形态有自己的摄像头，全程像真人一样能看能听，讲解时配视频动画演示。
- **年级范围**：先做二、三年级，整体目标是一到六年级。

下面各项的优先级还是 2026-11-23 定的，没有随定位调整。

扩到其他年级时要改的地方（2026-11-25 查代码）：

- 孩子的年级已经按 1–6 存储，课本古诗也覆盖了六个年级，这两处不用动。
- 小熊老师和小熊汉字的提示词写死了“二、三年级”（`server/src/board.mjs`、`server/src/hanzi.mjs`）。
- 验算只认整数算式，分数和小数还不行（`server/src/verify.mjs`）。
- 小熊老师的评测集 30 题都用同一个二年级孩子（`server/eval/teacher-cases.mjs`），每开一个年级要先补题。
