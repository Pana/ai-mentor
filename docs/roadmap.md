## 1. 作业管理：持续打磨体验

现在的重点。发现的问题随手记在这里，修好就勾掉。

- [x] 小米 Pad 拍照交作业时横竖屏切换，回来就退回了作业页（Android 旋转会重建 Activity，拍好的照片和当前页面都丢了）
- [x] 家长批注点“撤销”没反应（Android：撤销按钮读不到最新状态，一直是灰的）
- [x] 批注页的图片不能放大（Android：两指张开放大、拖动，右上角“还原大小”）
- [x] iPhone 批注页也加上两指放大（照片放进 PencilKit 画布里一起缩放，红笔用两指移动，打勾/圈出用单指移动）
- [ ] **AI 自动批改（不着急）**：家长打开批注页时，AI 先判断每道题对不对，在照片上预先标好 ✓ / ○，家长确认或修改后再发给孩子。要先解决的问题：
  - 识别准确率：小学口算、填空比较好判断，应用题、作文先不做
  - 标记位置要落到题目上（需要视觉模型给出题目的坐标）
  - 家长始终是最后确认的人，AI 只预标，不直接发给孩子
