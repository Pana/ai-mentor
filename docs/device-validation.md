# 平板实机验收清单（旧版辅导）

> 本清单针对 1.0.0-beta.1 的旧版辅导功能。安卓一期作业管理的验收清单见 [安卓一期](./android-phase1.md)。

状态：尚未执行。目标为 Android 小米平板，具体型号与 Android 版本待记录。当前用户只有 iPad，无法直接安装 APK；单元测试、Lint 和 APK 打包不能替代 Android 实机验证。

每次记录平板型号、Android 版本、App 版本、测试日期、结果及失败复现步骤。先使用示例数据；删除场景仅使用可丢弃的测试档案。

| 场景 | 操作与预期 |
| --- | --- |
| 安装与启动 | 安装 Debug APK，打开“先体验示例家庭”，页面正常显示，无崩溃 |
| 横竖屏与输入 | 切换方向，打开作业与输入框；按钮可触达，键盘不遮挡提交入口 |
| 数据隔离 | 在林林的数学示例中提交答案，切换琪琪；琪琪任务及学习证据不受影响 |
| 订正与证据 | 先答 32，再答 42；保留错误与订正记录，不能因此标为独立掌握 |
| 提示与掌握 | 使用提示后答对，知识状态为“学习中”；独立完成两个不同的同知识点示例题才为“初步掌握” |
| 真实家庭验证 | 清空示例数据，设置系统锁屏密码；建立家庭、进入家长空间时需要系统凭据，取消验证不能进入 |
| 家长界面离开 | 切后台再返回，家长界面重新锁定；检查拍照/相册返回后的验证及弹窗状态 |
| 作业与检查 | 添加真实作业、填写草稿、提交为待检查；家长标为待订正或完成，不生成示例题学习证据 |
| 相机与相册 | 拍照、选图、取消、移除图片；图片归属正确，不可用时有提示；照片能在重启后显示 |
| 重启恢复 | 填写草稿、答错或提交待检查后关闭 App 再打开，档案、任务状态、文字与证据恢复 |
| 草稿白板 | 手指或笔绘制、清空、暂停；离开页面后清空，与界面说明一致 |
| 本地朗读 | 安装离线中文语音包，朗读提示、停止朗读、切后台；没有语音包时给出明确提示 |
| 离线使用 | 断网后可读取和修改本地任务、查看已有图片与记录 |
| 删除隔离 | 删除一个测试孩子后，其任务、证据及关联图片被清理，另一个孩子的数据保留 |
| 清空家庭 | 确认清空后回到空家庭入口，重启不会重新填充示例数据 |

## 首版候选追加验收

| 场景 | 操作与预期 |
| --- | --- |
| 覆盖安装 | 从原型 0.1.0 覆盖安装 1.0.0-beta.1，现有档案、图片、作业和证据保留 |
| 教材与休息设置 | 修改昵称、年级、教材及提醒分钟数，重启后保留 |
| 编辑与删除作业 | 修改未完成作业后重置待开始并清除旧辅导上下文；删除后关联图片和记录被清理 |
| 真实作业证据 | 家长检查时填写知识点、具体依据与是否独立完成；未填知识点时只更新作业，不凭空生成掌握结论 |
| 学科隔离 | 两科填写同名知识点，记录分开；后续改作业学科不改变历史证据的学科 |
| 学习计时 | 设置 5 分钟提醒；暂停、后台、拍照期间不继续计时，回到页面由孩子继续；强制关闭最多丢失最后一次心跳之后的约 30 秒计时 |
| 进程恢复 | 学习中杀死进程后恢复到任务选择，不自动继续计时或录音；之前保存的草稿仍在 |
| 照片方向 | 横竖拍摄、相册导入带方向信息的照片，显示与发送方向正确 |
| 服务未配置 | 无网关设置时可使用本地功能，云端功能明确提示需家长配置 |
| 供应商未配置 | 网关启动但无模型配置时返回不可用，不伪造模型回复 |
| 识题确认 | 发送一张作业要求图片，识别结果可改；未勾选核对前不能保存识别草稿 |
| 文字与图片求助 | 用户明确勾选才发送当前题目图片；回复衔接当前孩子与任务，不混入其他孩子 |
| 修改期间回包 | 等待检查时修改答案、离开页面或切换孩子；旧回复不会应用到新题或新孩子 |
| 取消与断网 | 等待回复时停止或断网，原任务/答案保持；恢复后可以重试 |
| 检查边界 | 模糊图片或缺少答案返回无法判断；AI 建议不自动把作业设为完成、不自动写入知识掌握证据 |
| 生成题 | 新题包含三级提示和讲解；生成题作答标为待核验，不提升或降低可信掌握状态 |
| 语音输入 | 首次解释系统语音服务与授权；拒绝授权仍可打字；识别文字可改再发，点击说话会停止朗读 |
| 语音停止 | 停止、后台、离开页面后不再接受延迟识别结果；不会自动发送音频或识别文字 |
| 清空家庭与凭证 | 清空后服务设置也清空，新示例家庭不能继续使用原设备凭证 |

系统语音服务在不同小米系统版本上可能不可用，应记录实际服务与联网要求。iPad 不纳入本清单，因为当前客户端是 Android APK；若首发平台改成 iPad，需要另建 iPad 验收清单。外接 USB 摄像头、实时全双工语音和专项学科评测尚未完成，不计入本轮候选版验收通过项。供应商联调步骤见 [网关说明](../server/README.md)。
