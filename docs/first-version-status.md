### 本轮修复的已有问题

- 学科以中文发送给网关，网关只接受 `MATH`/`CHINESE`/`ENGLISH`，此前所有 iPad 求助都会被拒绝（400）。
- 照片保存为绝对路径，iOS 更新 App 后容器路径变化会导致图片丢失；改为只存文件名并兼容旧路径。
- 相册图片可能是 HEIC 或超过 2MB，网关只收 2MB 内 JPEG；现在保存时统一缩放并转为 JPEG。
- 侧边栏“我的作业”“我的进步”等页面无法进入（选中列表与按钮混用）；从学习页切换侧边栏时学习页残留。
- 本地 JSON 解析失败时会被空家庭覆盖；现在另存为备份并提示。旧格式数据可兼容读取。
- 设备凭证改为仅本机可用的钥匙串项，网关请求禁止跟随重定向，避免凭证外泄。

### iPad 第三轮（2026-11-06）

- 学习计时写入记录（每 30 秒、离开页面和切到后台时保存，重复保存不会减少时长），今日回顾显示学习分钟数。
- 按孩子设置的时长（5–60 分钟，默认 20）提醒休息并暂停计时。
- 家长设置可编辑孩子档案（昵称、年级、教材、休息时长）和未完成作业的题意；修改题意后作业重置并清除旧的小熊对话。
- 网关可单独配置视觉模型（`MODEL_VISION_NAME`），或在纯文本模型下明确拒绝图片请求；iPad 与 Android 客户端都显示对应提示。

### iPad 第四轮（2026-11-06）

- 拍题目改为 App 内摄像头预览：优先使用 USB-C 外接摄像头（iPadOS 17+），其次后置摄像头，可切换；只拍静态照片，不录视频。
- 拍照或从相册选图后进入框选，只保存并发送选中的题目区域（也可使用整张）。
- 语音识别在设备支持时只用本机识别，录音不离开 iPad。
- 网关遇到模型返回空内容（DeepSeek JSON 模式已知现象）自动重试一次。
- `scripts/provider-check.mjs`：读取 `server/.env`，用示例题和 `scripts/fixtures/homework.jpg` 检查真实服务商的求助、对错判断、识题和出题。

## 尚未验收 / 尚未完成

- 真实供应商的参数兼容性、图片理解、提示与判题质量、延迟和费用，需要接入信息后联调。
- 小米平板的安装、锁屏验证、相机/语音服务、横竖屏、后台/重启恢复，需要实机验收。
- iPad 不支持直接安装本项目 APK；要在 iPad 上使用，需要新建 iPad 原生或跨平台客户端，不能把当前 Android APK 直接转换使用。
- iPad SwiftUI 垂直切片已开始，但尚未在 Mac/Xcode 编译或安装；不能把它描述为已通过 iPad 构建。Linux 只完成源码、文档和网关测试。
- 当前语音是点击输入、确认发送、朗读回复，不是持续监听的实时全双工对话或自动语音打断。
- 外接 USB 摄像头预览与热插拔、硬件供电和对焦尚未实现专用接入；系统相机与相册可用作替代入口，仍需实机验证。
- 三科教材题库、朗读/背诵/跟读评分、听写与看图写话专项流程尚未完成；当前通用辅导和短答案练习不能替代全部学科专项能力。
- 自动判断长时间无进展并主动询问尚未实现；当前仅按约定学习时长提醒休息。
- 尚无学习数据备份恢复、跨设备同步、正式签名/分发及自动化设备测试。
- iPad 代码尚未在 Linux 上编译；当前环境没有 Swift、Xcode 或 iOS SDK。`project.yml` 可由 XcodeGen 生成 Xcode 工程，或按 iPad README 手动创建工程。

这是可安装、可配置服务联调的第一版候选，不能将构建与模拟测试通过等同于完整首版需求验收通过。

## Android 使用顺序（保留参考）

1. 安装本轮 Debug APK；已有原型可覆盖安装，先保留现有数据。
2. 先体验本地流程；实际家庭需平板设置锁屏密码，再进入家长空间创建档案和填写教材。
3. 按 [网关说明](../server/README.md)填写服务端配置并启动，通过 USB 转发或 HTTPS 连接。
4. 家长填写服务地址、设备凭证并开启云端辅导；供应商密钥只填写到服务端。
5. 按 [实机验收清单](device-validation.md) 与网关供应商验收项逐项记录。

原型阶段的构建记录保留在 [原型状态](prototype-status.md)，后续应以本文为当前状态。
