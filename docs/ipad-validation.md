# iPad 实机验收清单

状态：iPad 为首发平台。已在 Xcode 27.2 编译通过并在 iPad 模拟器启动；尚未在真实 iPad 安装。记录 Mac 型号、macOS、Xcode、iPad 型号、iPadOS、App 版本、测试日期和结果。

| 场景 | 操作与预期 |
| --- | --- |
| Mac 工程与签名 | `cd ipad && xcodegen generate`，打开工程，选择个人 Team；Build 成功，无签名错误（模拟器编译已通过 2026-11-06） |
| 安装与启动 | 连接 iPad，信任 Mac，开启开发者模式，Debug 安装并启动；无崩溃 |
| 首次入口 | 空家庭显示入口；选择示例家庭后进入学习首页，关闭重开后本地 JSON 仍保留 |
| 孩子切换 | 左侧孩子列表切换林林/琪琪；首页与作业列表只显示当前孩子的数据 |
| 家长门禁 | 进入家长设置要求 iPad 锁屏密码或 Face ID；取消或失败不能修改服务配置；退出后再次需要验证 |
| 作业录入 | 添加学科、标题和要求；重启后任务仍在，数据只保存在 App Support |
| 摄像头预览与框选 | 点“拍题目”看到实时画面；横竖屏旋转画面方向正确；拍照后可拖动选框和四角，“使用选中区域”后预览只剩所选题目；接入 USB-C 外接摄像头时默认使用它，可在右上角切换 |
| 照片选择与拍摄 | 选择或拍摄一张题目图片；学习页预览正确；未经勾选不发送图片；图片保存成功后重启仍可显示 |
| 草稿与提交 | 输入草稿、提交待检查；切换页面后状态和草稿保留 |
| 网关配置 | 家长填写 HTTPS 地址与设备凭证；凭证存入 Keychain，供应商密钥不在客户端 |
| AI 文字求助 | 网关正常时能发送当前任务文字，显示回复和检查建议；无网关时明确提示并保留作业 |
| AI 图片求助 | 明确勾选后才发送当前图片；模型失败或超时不改变作业状态 |
| 断网与取消 | 请求中断网、离开页面或关闭 App；本地草稿和作业不丢失，可重新求助 |
| 键盘与横屏 | iPad 横屏输入时提交和导航按钮可见；键盘收起后布局恢复；分栏可折叠 |
| 拍照识题 | 添加作业时拍一张作业，点“识别作业要求”；结果填入名称和要求，未勾选“已核对”不能保存；取消后图片被删除 |
| 练一练与复习 | 本地练习答错后出现“复习安排”；用提示后答对不计“独立完成”；AI 生成题标“AI 生成练习” |
| 白板 | 手指与 Apple Pencil 都能书写；清空可用；离开学习页后草稿清空 |
| 学习计时与休息 | 家长把休息时长设为 5 分钟；学习页计时 5 分钟后弹出休息提醒并暂停；切到后台再回来计时暂停；“我的进步”显示今日学习分钟数 |
| 家长编辑 | 修改孩子年级和教材后，求助请求使用新年级；修改作业题意后作业回到“待开始”，旧对话清除 |
| 停止请求 | 求助中点“停止”、返回或切换孩子，请求取消且不写入回复 |
| 删除与清空 | 删除测试数据后图片、作业和证据清理；清空家庭后服务配置按产品要求保留或清除并记录结果 |

第一轮不验收实时全双工语音、外接 USB 摄像头、TestFlight 和 App Store 发布。个人 Apple ID Debug 安装足以验证本地切片；发布签名另行配置。
