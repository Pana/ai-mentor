# 安卓一期：作业管理

日期：2026-11-13
对应需求：[一期需求：作业管理](./prd-phase1.md)；对应技术方案：[一期技术方案](./tech-plan-phase1.md)

安卓端实现了和 iOS 一期相同的作业管理流程，服务端接口不变，两端可以混用：例如家长用 iPhone、孩子用安卓平板，或家长用安卓手机、孩子用 iPad。

## 范围与取舍

| 事项 | 决定 |
| --- | --- |
| App | 沿用 `app/`（包名 `cn.littlebear.tutor`，可覆盖安装）。首次启动选“我是家长”或“这是孩子的设备”。旧版辅导代码保留在仓库里，但不再提供入口 |
| 设备与角色 | 按选择的角色区分，不按设备区分：家长端、孩子端在手机和平板上都能用。宽度 ≥ 600dp 时使用平板布局 |
| 奖励时间锁定 | 只记账和倒计时，不锁定其他 App（iOS 当前也一样）。以后如需锁定，可选无障碍服务拦截或设备所有者模式 |
| 推送 | 前台每 20 秒同步一次，回到前台时立即同步。很多国内安卓设备没有 FCM，以后如需推送，考虑接入厂商推送 |
| 家长验证（孩子设备） | 使用系统锁屏密码（`KeyguardManager`）；设备没有设锁屏时给出提示 |

## 代码结构（`app/src/main/java/cn/littlebear/tutor/homework/`）

| 文件 | 内容 |
| --- | --- |
| `Api.kt` | 接口数据类型、错误文案、OkHttp 客户端（不跟随重定向）、服务器地址校验 |
| `Store.kt` | 本机唯一数据源：服务端数据缓存、`/v1/changes` 增量同步、离线提交队列、家长端操作。逻辑和 iOS `Store.swift` 一一对应 |
| `Platform.kt` | 设备凭证用 Android Keystore 加密保存；照片处理（EXIF 旋转、缩放、2MB 以内 JPEG）；录音（AAC/MP4）与播放 |
| `Design.kt` | 配色、科目和评分样式、小熊、远程图片、批注叠加 |
| `HomeworkApp.kt` | 入口、首次连接、前台轮询、错误提示 |
| `ParentScreens.kt` | 家长端：作业、录入（AI 整理 / 手动）、核对、详情、修改、每天坚持、奖励规则、设置与配对 |
| `ParentReview.kt` | 批改：红笔、打勾、圈出、撤销，导出每页一张透明 PNG（与 iOS 互通），打分与评语 |
| `ChildScreens.kt` | 孩子端：选头像、今天、全部作业、拍照交作业（多页）、计时、录音、看批改与订正、奖励时间、家长设置 |

调试版允许用 HTTP 连接本机、模拟器宿主（`10.0.2.2`）和家庭局域网地址，方便联调；正式版只允许 HTTPS。

## 自动化验证

| 命令 | 覆盖 |
| --- | --- |
| `./gradlew testDebugUnitTest lintDebug assembleDebug` | 单元测试（日期、地址校验、错误文案、离线队列与缓存）、手机和平板截图渲染、Lint、APK |
| `scripts/android-phase1-e2e.sh` | 启动临时服务端，用安卓数据层跑完整流程：家长连接 → 添加孩子 → 配对 → 录入三种作业 → 孩子离线拍照（排队，联网后补传）、计时、录音 → 家长批注批改并要求订正 → 订正后再批改 → 奖励入账与补差 → 使用奖励时间与每日上限 → 每天坚持上限 → 删除同步 → 重启读缓存 → 撤销设备 |

截图测试（`ScreenshotTest`）用 Robolectric 在 JVM 上渲染界面，输出到 `app/build/screenshots/`，包括手机竖屏和平板横屏下的家长端和孩子端。它能确认界面可以渲染、布局合理，但不能代替真机。

## 真机验收清单

状态：尚未执行。每次记录设备型号、Android 版本、App 版本和日期。

| 场景 | 操作与预期 |
| --- | --- |
| 连接 | 家长手机用服务器地址和家长密钥连接；生成配对码，孩子设备 10 分钟内配对成功 |
| 录入 | 粘贴含三科的群消息，AI 拆成三项；逐项修改后加入，孩子设备 20 秒内看到 |
| 拍照提交 | 孩子拍 2 页、从相册选 1 页，横竖拍摄方向都正确；暗的照片有提醒；家长端看得清楚 |
| 离线 | 孩子设备断网后提交，显示“等网络上传”；联网后自动补传，按设备时间判断是否按时 |
| 计时 | 计时未满不能打卡；切到后台计时暂停；满时长打卡后获得奖励 |
| 录音 | 首次录音时弹出麦克风权限；拒绝后有提示；录音能回放，家长端能播放 |
| 批改 | 红笔、打勾、圈出、撤销正常；多页作业可以逐页批注；孩子端看到的红笔和照片对齐 |
| 订正 | 要求订正后孩子重拍提交，家长再批改，奖励补上差额 |
| 跨平台 | 安卓家长批改 iPad 孩子的作业，以及 iPhone 家长批改安卓孩子的作业，批注都对齐 |
| 奖励时间 | 作业没交完、不在时段、超出每日上限时都不能用；倒计时结束有提示 |
| 家长设置 | 孩子设备上点“家长”需要锁屏密码；断开后要重新配对 |
| 手机和平板 | 家长端和孩子端在手机竖屏、平板横竖屏都能用，按钮可点，键盘不遮挡提交按钮 |
| 覆盖安装 | 从 1.0.0-beta.1 覆盖安装后进入新的角色选择页，不崩溃 |
