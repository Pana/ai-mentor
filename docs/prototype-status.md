# 原型实现与验证状态

更新时间：2026-11-04。范围：当前工作区中的 Android 原型源码。

本文保留 0.1.0 原型阶段记录；当前版本与剩余工作以 [首版候选状态](first-version-status.md) 为准。

## 已实现的原型功能

- 家庭入口、示例家庭、多个孩子档案、家长与孩子界面。
- 实际家庭使用设备锁屏凭据进入家长空间；示例家庭公开体验。
- 按孩子隔离的作业、作答证据与知识状态。
- 手动添加作业、调用系统相机拍照、从相册选择图片；图片保存在 App 私有目录。
- 真实作业的开始、草稿记录、提交家长检查、订正与完成流程。
- 数学、语文、英语各两道固定示例题，逐级提示、答案检查及学习证据。
- 区分“作业完成”和“初步掌握”；提示后答对或错误后订正不算独立完成。
- 本地 JSON 原子写入；读取失败时保留原文件并停止继续写入。
- 孩子档案及关联数据删除、家庭数据清空。
- 小熊形象、临时草稿白板、设备离线中文 TTS 朗读及停止。

以上表示源码已有实现；设备权限、生命周期、界面适配及持久化体验还需实机验证。

## 未实现的产品能力

- 云端 AI 辅导及配套鉴权服务。
- 照片 OCR、手写题目识别、真实作业自动批改。
- 麦克风输入、语音识别、自然语音对话与语音打断。
- 外接 USB 摄像头预览与兼容性验证。
- 按学校教材组织的题库、动态生成练习、间隔复习计划。
- 作业与孩子教材信息编辑、学习数据备份与恢复。
- 完整辅导会话、休息计时及主动提醒。

现有“练习”和“知识档案”只验证固定示例流程；系统朗读不是 AI 语音对话。真实作业不会按示例答案判分。

## 本轮工程工作

- 恢复本机 JDK 17、Android SDK 35、Build Tools 34.0.0，工具保存在被忽略的 `.tooling/` 目录。
- 补齐标准 Gradle 8.9 Wrapper，固定官方分发包 SHA-256。
- 调整为适合当前机器的 1536MB 堆、单 worker、进程内 Kotlin 编译。
- 补齐 README、开发与迁移说明，以及平板实机验收清单。
- 将本地图片加载改为显式 Compose 状态配合 `LaunchedEffect`，解决当前 Lint 工具对 `produceState` 赋值的检查阻断；仍在 IO 线程解码图片。
- 更新废弃的 Compose 曲线路径 API 与方向图标 API。
