## 1. 一期目标

只做好一件事：**作业管理**。家长把老师布置的作业交给 App，孩子按时完成并提交，家长批改，孩子靠完成情况换取奖励时间。

```
家长录入（iPhone） → 孩子查看、完成、提交（iPad） → 家长批改（iPhone）
       ↑                                                   ↓
       └──── 需要订正：孩子订正后再提交 ←──── 评分 → 奖励时间（iPad）
```

## 2. 设备与角色

| 设备 | 使用者 | 主要功能 |
| --- | --- | --- |
| iPhone | 家长 | 录入作业、设置每天坚持、查看完成情况、批改、设置奖励规则 |
| iPad | 孩子 | 查看作业、完成作业、拍照提交、看批改、使用奖励时间 |

- 两台设备的数据**通过项目自有服务端同步**，服务端是唯一的数据来源；设备上只保留缓存，断网时可以查看已有内容。
- 一个家庭可以有多个孩子。家长端可以切换孩子；iPad 上用头像选择是哪个孩子在用。
- iPad 上保留一个需要家长验证的小入口，只用于设备相关的设置（例如选择奖励可用的 App）。

## 3. 作业的两种类型

| 类型 | 说明 | 例子 |
| --- | --- | --- |
| 当天作业 | 一次性的，由家长从老师的通知录入 | 口算练习册第 12 页；背诵《咏柳》 |
| 每天坚持 | 规律性、重复性的作业，按设定的日子自动出现 | 每天英语朗读 5 分钟；周一到周五口算 10 道 |

每天坚持**每个孩子最多 5 项，建议 3 项**。加到第 4 项时提醒“项目太多，孩子容易坚持不下来”；满 5 项后不能再加，只能先暂停或删除一项。

## 4. 家长端（iPhone）

### 4.1 录入作业

核心输入是**一段文字**，通常是从班级群复制的老师原话，可以再附几张图片（作业单、课本页）。

1. 家长粘贴文字，选择给哪个孩子（可多选），可以添加图片。
2. 点“让 AI 整理”，大模型对内容做一次性处理：
   - **判断科目**。一条消息里如果有多个科目，就拆成多项，每项一个科目。
   - **清洗文字**：去掉口语、寒暄、表情代码（如 `[抱拳]`），改写成简洁的作业要求。
   - **提取老师的截止时间**，例如“明早交”“周一交”。原话没提的，视为当天作业。
   - **建议完成方式**：线下（本子上写，拍照交）或在线（在 iPad 上做）。
   - **单独标出“家长要做的事”**，例如签字、检查背诵。这些不算孩子的作业。
3. 家长逐项核对，科目、日期、内容、完成方式都可以修改，然后确认加入。
4. 加入后推送到孩子的 iPad。

也可以不用 AI，直接手动填写。原始粘贴的文字保留，可以随时对照。

每项作业的基本信息：**科目、日期、内容**；另有完成方式、老师截止时间、附件图片、家长要做的事。

科目：语文、数学、英语，以及“其他”（老师可能布置科学、道德与法治等）。

### 4.2 每天坚持

设置项目名称、科目、完成方式（在线计时 / 计时并录音 / 线下拍照）、时长或数量、频率（每天 / 周一到周五 / 自选星期）。可以暂停、恢复、删除。

### 4.3 完成情况

- 按**日期分组**显示每项作业的状态，可切换孩子。
- 顶部显示“等你批改”的数量，点进去直接批改。
- 每天坚持显示当天打卡进度。

### 4.4 批改

1. **批注**：在孩子提交的照片上用红笔、打勾、圈出、写字，可以撤销。在线作业的录音可以回放。
2. **打分**：优 / 良 / 中 / 再努力。
3. **评语**：自由文字，提供常用短语快捷输入。
4. **要求订正**：打开后，孩子需要订正并重新提交；家长重新批改。

### 4.5 奖励规则

见第 6 节。

## 5. 孩子端（iPad）

### 5.1 查看作业

- **今天**：今天要做的作业按顺序排好，每项标明完成方式；旁边是每天坚持的打卡清单、最新的批改结果和奖励时间入口。
- **全部作业**：按日期分组，可筛选“还没做完 / 等家长批改 / 有批注”。

### 5.2 完成作业

| 完成方式 | 孩子怎么做 |
| --- | --- |
| 线下 | 在本子上写，写完点“拍照交作业”，可以拍多页，拍得不清楚时提醒重拍 |
| 在线 | 在 iPad 上直接做。一期支持计时类（朗读、阅读）和录音类（朗读、背诵） |

提交后状态变为“等家长批改”。

### 5.3 看批改

看到红笔批注、评分、评语和这项作业得到的奖励。要求订正的，改好后再拍照提交。

## 6. 激励：奖励时间

孩子完成作业可以攒“奖励时间”（分钟），用来看动画或玩游戏。攒多少取决于**完成质量**和**是否按时**。

### 6.1 怎么攒（家长可调整数值）

| 条件 | 默认奖励 |
| --- | --- |
| 按时提交 | +5 分钟 |
| 评分 优 / 良 / 中 | +5 / +3 / +1 分钟 |
| 订正后评分提高 | 补上差额 |
| 每天坚持打卡一项 | +3 分钟 |
| 连续打卡 7 天 | +10 分钟 |

**按时**：在家长设置的**每天完成时间**（默认 19:30）之前提交。老师规定的截止时间几乎都是“明早”，起不到激励作用，所以只用来排日期和提醒，不用来算奖励。

### 6.2 怎么用（家长可调整）

- 当天作业全部提交后才能用（默认开）。
- 每天最多用 30 分钟。
- 只能在设定的时段使用（默认 19:00–20:30）。
- 只能打开家长选好的动画和游戏 App。时间用完自动锁上。

### 6.3 锁定方式

一期采用系统“屏幕使用时间”能力：平时锁住选定的 App，孩子用奖励时间时临时解锁，到时间自动重新锁上。孩子的 iPad 登录的是孩子自己的 Apple ID，由家长批准授权，孩子不能自行关闭。在 App 里自带动画和游戏放到以后再做。

## 7. 作业状态

```
还没开始 → 已提交（等批改） → 已批改（优 / 良 / 中 / 再努力）
                         ↘ 要订正 → 订正后再提交 → 已批改
```

- 状态由服务端统一维护，两端看到的一致。
- 在线作业完成即视为提交；只计时、不需要家长看的每天坚持，打卡即完成。

## 8. 通知

| 事件 | 通知对象 |
| --- | --- |
| 家长加入新作业 | 孩子的 iPad |
| 孩子提交作业 | 家长的 iPhone |
| 接近每天完成时间仍有作业没交 | 孩子的 iPad |
| 接近老师的截止时间仍没交 | 家长的 iPhone |
| 家长批改完成 | 孩子的 iPad |

## 9. 数据与隐私（相对 v0.3 的变化）

- 作业、提交的照片和录音、批改记录、奖励记录**保存在自有服务端**，用于两台设备同步。这改变了 v0.3 中“服务端不持久保存学习内容”的原则。
- 只有调用 AI 整理作业时，才把作业文字（和可选图片）发给模型供应商；孩子提交的作业不发给模型。
- 服务端日志不记录作业内容、图片和录音。
- 家长可以删除单项作业、单个孩子的全部数据或整个家庭的数据，服务端同步删除对应文件。
- 必须通过 HTTPS 访问服务端。

## 10. 一期不做

- 小熊辅导对话、语音对话、白板（现有代码保留，一期界面不突出）
- 知识点档案、学习证据、练习与复习安排
- 拍照识题后的逐题判对错
- App 内自带的动画和游戏
- Android 客户端

## 11. 验收场景

| 场景 | 关注点 |
| --- | --- |
| 粘贴一条含三科的群消息 | 拆成三项、科目正确、口语和表情去掉、截止时间正确，家长能逐项修改 |
| 录入后 iPad 收到 | 孩子端在合理时间内出现新作业，并收到通知 |
| 线下作业拍照提交 | 多页照片完整上传，家长端收到通知，断网时能排队，联网后补传 |
| 在线朗读打卡 | 计时满才能打卡，录音能在家长端回放 |
| 批改与订正 | 批注、评分、评语在 iPad 上显示一致；订正后再批改，奖励补差额 |
| 每天坚持上限 | 第 4 项提醒，第 6 项无法添加 |
| 奖励计算 | 按时、评分、打卡、连续天数的奖励都正确入账，不重复入账 |
| 奖励使用 | 作业没交完不能用；超出每天上限不能用；到时间自动锁上 |
| 两个孩子 | 作业、提交、奖励互不混淆 |
| 删除数据 | 服务端和两端对应记录、文件都被删除 |
