# 小熊读诗配图画法（古风工笔）

给小学一到六年级的孩子看的古诗配图。张数按诗的意思定：意思上一个独立的画面画一张，不凑数，也不硬拆。整首写同一个画面就一张，有场景、时间、动作变化才多画。一张对应一句或几句，按诗的顺序讲一个连贯的小故事。定稿样张在 `examples/`：《静夜思》（夜景、室内和庭院）和《咏鹅》（白天、池塘、剖面）。新画的图要和样张放在一起像同一套书。

## 画面

- SVG，`viewBox="0 0 800 600"`（4:3），不写 `width`/`height`。
- 只用 SVG 自己画：不引用外部图片、字体文件、链接，不用 `<image>`、`<foreignObject>`、`<script>`、事件属性（`onload` 等）、CSS `@import`。
- 一张图的文件控制在 40 KB 以内。形状要简洁，不要堆几千个点的路径。
- 画面里除了右下角的印章，不写任何文字（诗句由页面另外显示）。

## 固定的版式

照样张原样保留，每张都有：

1. 底色：`<rect width="800" height="600" fill="#efe3c6"/>`（绢色）。
2. 纸纹：样张里 id 以 `-grain` 结尾的 `feTurbulence` 滤镜，整张盖一层 `opacity=".4"`。
3. 边框：两道框（`x=12` 宽 3、`x=20` 宽 1，颜色 `#7b3b2a`），四角各一个 16×16 的实心小方块，里面一个 8×8 的绢色描边方块。
4. 印章：右下角 `translate(732 514) rotate(-3)`，40×44 圆角矩形 `#b3372b`，竖排两个楷体字（`font-family="STKaiti, KaiTi, 'Kaiti SC', serif"`，`#f7ead8`，16 号），用作者名里的两个字（李白、宾王、杜甫）；作者是佚名或民歌时用诗题里的两个字。

## 线条和颜色

- 所有实体形状都有墨线：`stroke="#2a1f17" stroke-width="1.8" stroke-linejoin="round" stroke-linecap="round"`。细节线（衣褶、羽毛、窗格回纹）用同色或底色，宽 1–2.4。
- 矿物色，不用荧光色、不用纯黑大面积填充：
  - 石青 `#2f7276` / 深 `#245b5f` / 滚边 `#1d4a4d`；石绿 `#3f7a6d`、`#7aa68f`、`#5c9a7c`
  - 朱红 `#b9442f`、`#c0392b`；赭石木色 `#8a3f2c`、深 `#552619`
  - 金黄 `#d8a443`、`#b5842d`；绢白 `#f4ecd8`、`#fbf8ef`
  - 墨 `#2a1f17`、发色和帽子 `#1d1a18`、肤色 `#f3dcc2`
- 夜景：天空渐变 `#0f2437` → `#21435d`；月亮 `#f8eecb`，带两道淡淡的光晕环和几块 `#e6d6a6` 的月面；室内用一层径向渐变把四周压暗（中心留在月光或灯光处）。
- 白天：天空渐变 `#cfe0d6` → `#eef0dc`；远山两层 `#a9c5b4`、`#7aa68f`；水面 `#6aa999` → `#2f7276`，水纹用 `#e3f1ea` 的短横线。
- 季节靠景物和颜色表现：春天柳树、桃花、梅花；夏天荷叶荷花；秋天枫叶 `#c0582f`、芦苇、大雁；冬天雪用绢白、枝条光秃。

## 人物

- 唐宋人物，侧身为主，面朝画面里他看的东西。同一首诗的几张图里，同一个人物的衣服颜色、帽子、发型、比例保持一致。
- 成人：幞头（黑色帽子 + 后脑小髻 + 两条垂带），交领宽袖长袍，腰带，衣摆有深色滚边，袍子上两三道衣褶。诗人一般石青色袍子，可以按诗换颜色（但同一首诗里不换）。男性成人可以有小胡子。
- 孩子：两个小发髻（总角），短衣长裤，脸圆，眼睛大一点，带一点腮红。
- 人物要大：站着的成人从脚到头顶约占画面高度的一半（约 280–320 像素），孩子一眼能看清动作和表情。
- 手从袖口露出一点（肤色小椭圆）；不要画成圆球形的袖子。
- 表情温和。闭眼用一道弧线，睁眼用小黑点。

## 讲故事

- 每张图对应的诗句写清楚它画的是哪一句里的什么：景物、动作、情绪。诗里没有的东西少加，加的要合理（唐代的房子、器物、衣服）。
- 诗人的感情用画面表达：思乡可以画云朵里浮现的家乡（像《静夜思》第 4 张，用一串小圆圈连到人物头边），离别画远去的船帆，边塞画辽阔的沙漠和孤城。
- 战争、死亡、悲伤的诗要画得含蓄，适合小学生：不画伤口、血、尸体、武器伤人；用远景、背影、天气和景物表达。
- 动物和植物按真实的样子画（鹅的橙色嘴和额头肉瘤、柳叶细长、荷叶圆而有叶脉）。
- 构图留出呼吸的空间，主体放在三分线附近；前景、中景、远景分层，远景颜色淡。

## 技术约定

- 渐变、滤镜、裁剪路径放在 `<defs>` 里，id 用短的英文（脚本会自动加上诗和图的前缀，避免同一页面里重名）。
- 每张图独立，不引用别的图里的 id。
